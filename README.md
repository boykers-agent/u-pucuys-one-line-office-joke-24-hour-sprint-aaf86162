A single-line joke about office life, the sort of line you send a colleague after a meeting that should have been an email.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
This meeting could have been an email, but the email would have needed a meeting to explain why it was not a meeting.
```
